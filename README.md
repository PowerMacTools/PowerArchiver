# PowerArchiver

Modern archive manager for Classic Mac OS

## Supported formats include:

- bzip2
- gzip
- lzip
- lzma
- xz
- uu
- rpm
- lrzip
- lzop
- grzip
- lz4
- zstd
- ar
- cpio
- lha
- tar
- xar
- warc
- 7zip
- cab
- rar
- rar5
- iso9660
- zip
- classic .sit and raw .sea payloads
- StuffIt 5 archives
